`main.py` writes one joke about crypto and trading life — a rule, the
violation, and the kicker that hands the blame back to the trader — to
`/output/entry.txt` (163 characters, one line, no trailing newline).

Run: `python3 main.py` — deterministic, two runs byte-identical.
